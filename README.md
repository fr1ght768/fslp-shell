## FSLP (Fr1ght's Shell Like Program)
simple shell like program for windows written on c

## Features
- 'ls' - list files in current direcrtory
- 'mkdir' - create directories in current directory
- 'rmdir' - delete directories in current directories
- 'cd' - change current directory
- 'clear' - clears output
- 'quit' - to exit the program
